# 踢一下（私聊嘴替工具）v1.0.0

**踢一下（私聊嘴替工具）** —— 用一句口语，让机器人按你保存的人格去私聊或群里 @ 对方。对方回复后，先用同一人格把原话修饰成**转述**发回给你，再交给 AstrBot 正常聊天继续；窗口内相关的新消息也会继续按人格转述。

## 两种发送方式

| 用户说法（口语即可） | 发送方式 |
| --- | --- |
| “帮我**私聊**一下 @张三，问明天几点集合” | 私聊张三，等回复后转告发起人 |
| “帮我**私聊**一下 小明，问明天几点到” | 按群名册里的昵称找到小明并私聊 |
| “帮我**私信**张三，说我会晚到十分钟” | 私聊张三 |
| “帮我跟 @张三 说一声，明天下午三点集合” | 在群里 @ 张三 说这句话 |
| “**在群里** @ 他一下，提醒带材料” | 在群里 @ 对方 |

规则（插件会再校验一次，不只看模型自觉）：

1. 只要指令里出现 **私聊 / 私信 / 私下 / 悄悄 / 单独 / 小窗 / 私密 / dm / pm** 等字样，就走私聊。
2. 没有这些字样、且当前在群里，就走群内 @ 目标发送。
3. 在私聊窗口里给机器人下指令也可以，但同样要带“私聊”等字样；不带的话插件会要求说清楚，**不会**擅自把内容公开到群里。
4. 在群里明确说“在群里 @ 他 / 公屏 / 当众”时优先群内发送；“别在群里说”这类否定句不会误判成群发。

## 主要能力

- **只发一条**：按人格私聊一条，立即回报已发出；对方首次文字回复后，**用同一人格把原话修饰成转述**发给发起人，任务结束，后续由正常聊天接管。
- **窗口内跟转**：首次回复后的一段时间内，对方再发来消息，若 LLM 判断仍与先前话题相关，就继续按人格口吻转述给发起人；无关消息不转述。跟转有次数上限，且**只转述、不再向联系人发送任何内容**。
- **人格转述回报**：回报正文是原话经人格口吻改写后的转述，不增加事实、不删关键信息；原话仍保存在数据库里。转述生成失败时自动回退为原话并标注。
- **群名册**：每天定时（默认凌晨 4 点）通过 OneBot 拉取机器人所在群、群成员昵称与 QQ，存到本地 `roster.sqlite3`；群里 @ 机器人并 @ 别人时也会即时收录被 @ 的人。
- **按昵称私聊**：群内可直接说“私聊小明”，按名册匹配 QQ；同群精确匹配，私聊里只有跨群唯一时才匹配，避免同名误发。
- **群临时会话**：机器人没加对方好友、普通私聊发送失败时，自动改走群临时会话（`send_private_msg` + `group_id`，需 NapCat 等协议端支持）；仍失败会明确回报“未发送”。
- **退订私聊**：对方在私聊里发 `/td 2小时`、`/td 3天`、`/td 永久` 后，机器人不再主动私聊他，但群里 @ 他照常；`/td 取消` 恢复。
- **人格化确认**：工具成功后，插件会用同一人格另生成一句确认（如“主人～已经私聊小明啦”），并在发送前替换掉主模型的普通回复，避免出现“已经私聊转达了”这种没有语气的话。
- **长文本分条**：人格化转述、首条私聊或群内 @ 超过单条上限时，按句号/换行自动拆成多条发送，不再截断。
- **群内 @ 代说**：没有私聊字样时在群里 @ 目标说话，由模型简短确认，不跟踪群回复。
- **使用保存的人格**：可指定人格 ID；未指定时读取发起会话实际生效的人格（含会话级覆盖）。只复制提示词与风格样例，不转发发起会话历史、密钥、工具或长期记忆。
- **自动回报**：私聊任务的详细结果固定发到发起人在原平台的私聊，不回到群里复述。
- **权限与黑名单**：默认所有人都能用，只有黑名单被拒绝；管理员（AstrBot 的 `admins_id` 加 `extra_admins`）可以在聊天里拉黑、解除拉黑、查看黑名单。目标必须来自真实 @、群名册昵称、明确 QQ 号或 contacts，不凭空猜；同一联系人同时只有一条私聊任务，全局最多 20 条。
- **以发起人为主语**：私聊首条会明确写成“云理（发起人昵称）希望我转告你……”；委托内容里的“我／找我／我的”都会改写成发起人，不会被当成机器人或人格自己；不再声明“我是机器人”。
- 只支持文字。不自动加好友、不查陌生人、不发媒体、不跨平台搜索。

## 安装

1. 建议 **AstrBot 4.29.1 或更新版本、Python 3.10+**。已在云端 AstrBot 4.29.1 上核对所需接口（人格解析、`llm_generate`、`send_message`、`At`、工具注册）；尚未在真实群聊里联调，旧版不保证兼容。
2. 把整个 `astrbot_plugin_persona_delegate` 文件夹复制到 AstrBot 的 `data/plugins/`，或通过插件管理器导入当地 ZIP。不要只复制 main.py。
3. 重启 AstrBot 或重载插件；默认所有人可用，按需在配置里填黑名单（以及可选的 contacts），保存并重载。
4. 在 AstrBot 设置中启用聊天模型工具调用，并允许工具 `persona_relay_message` 与 `persona_chat_control`；人格若限制了工具，也要把这两项加入。群聊通常需要 @机器人 触发。
5. 在 AstrBot 人格管理中建立人格；发起会话选中它，或在指令里明确人格 ID。

本插件只使用 Python 标准库和 AstrBot SDK，无额外 pip 依赖。

## 配置示例

适配器实例 ID 假设为 `qqbot`，你的账号是 `111111`：

```json
{
  "blocked_users": [],
  "extra_admins": [],
  "contacts": ["张三=qqbot:FriendMessage:222222"],
  "allow_mentions": true,
  "allow_raw_target": false,
  "provider_id": "",
  "persona_style_extra": "",
  "persona_status_reports": true,
  "max_message_chars": 1200,
  "timeout_seconds": 300,
  "followup_window_seconds": 1800,
  "followup_max_relays": 10,
  "allow_nickname_target": true,
  "roster_sync_enabled": true,
  "roster_sync_hour": 4,
  "roster_sync_timezone": "Asia/Shanghai",
  "temp_session_enabled": true,
  "llm_timeout": 60,
  "retention_days": 7
}
```

**注意：** `qqbot` 必须是你实际的适配器实例 ID（在适配器配置或日志的 unified_msg_origin 中核对），不是固定值，也不一定是 `aiocqhttp` / `telegram` 这类类型名。会话格式为 `平台实例ID:FriendMessage:账号`。

- `allow_mentions`（默认开）：口语里 @对方或直接写 QQ 号即可当目标。关闭后只能使用 contacts 联系人。
- `allow_raw_target`（默认关）：只影响其他任意账号写法；@、QQ 号、contacts 已经够用，通常无需开启。
- `contacts` 是可选的别名/白名单，适合常用联系人。
- `provider_id` 留空跟随发起会话；填写时用 AstrBot 里的提供商 ID。私聊消息和跟转转述都由该模型按人格生成。
- `persona_style_extra`：额外风格要求，追加到人格提示词后，例如“称呼我主人、句尾带～、多用颜文字”；留空只用保存的人格。
- `persona_status_reports`：状态回报人格化，默认开；“已传达/对方还没回”会用人格口吻发，关掉则发机械格式。
- `max_message_chars`：单条消息最大字数，默认 1200；私聊首条、转述回报、群内 @ 超过这个长度时，会按句号/换行自动拆成多条发送。
- `timeout_seconds`：发出私聊后等待回复的时长，默认 300 秒；超时任务结束并回报。
- `followup_window_seconds`：首次回复后的跟转窗口，默认 1800 秒；填 0 关闭跟转。
- `followup_max_relays`：单个任务最多跟转次数，默认 10；填 0 关闭跟转。
- `allow_nickname_target`：允许用群昵称指定对象，默认开。
- `roster_sync_enabled` / `roster_sync_hour` / `roster_sync_timezone`：每天在指定时区的小时（默认 Asia/Shanghai 的 4 点）同步群名册；也可用 `/代聊 名册` 手动立即同步。
- `temp_session_enabled`：普通私聊失败时改用群临时会话，默认开；需要协议端支持。

## 使用样例（QQ 群）

```text
@机器人 帮我私聊一下 @小明，问他明天几点到
@机器人 帮我私信一下 222222，说我今晚加班，晚点回
@机器人 帮我跟 @小明 说一声，明天下午三点集合
@机器人 在群里 @ 他一下，提醒带材料
```

私聊窗口里同样可以：

```text
帮我私聊一下 222222，问明天几点到
看看我的代聊进行到哪了
取消我发起的所有代聊任务
有哪些保存的人格？
```

模型应把目标理解为“消息里 @ 的人 / 直接给的 QQ 号 / 已配置别名”。**消息里真实的 @ 优先**：即模型把昵称写错，也以被 @ 的账号为准。如果模型没调用工具、或把“私聊”理解错，先检查工具调用记录；工具返回的才是真实状态。

确定性管理命令（同样受权限约束，群聊和私聊都可用）：

```text
/代聊 进度
/代聊 取消
/代聊 取消 任务ID
/代聊 联系人
/代聊 名册
/代聊 人格
/代聊 拉黑 123456
/代聊 解除拉黑 123456
/代聊 黑名单
```

## 退订私聊（/td）

任何人在私聊里发：

```text
/td 2小时
/td 3天
/td 永久
```

机器人就会停止主动私聊他；退订期间群里 @ 他、群内代说照常。恢复用：

```text
/td 取消
```

- 进行中的私聊任务会立即停止，并向发起人发送**按人格口吻**写的通知：“对方在 2 小时/3 天/永久内不想收到机器人私聊”。
- 之后有人试图私聊他，会直接提示“对方已退订私聊（还剩 X）”，只能群内 @。
- 退订只拦截机器人主动私聊（任务消息、回报、群临时会话），不阻止对方回复或群内互动。
- 到期自动失效；时长范围 1 小时到 10 年，永久用“永久”。
- 退订记录存在 `optout.sqlite3`，只影响对应平台账号。

## 权限与黑名单

- **默认所有人可用**：只要能触发机器人（群里 @ 或私聊），就可以发起代聊，没有白名单限制。
- **静态黑名单**：配置 `blocked_users` 填 `平台:账号` 或纯账号，重启/重载后一直生效。
- **运行期黑名单**：管理员直接说“拉黑 123456”“解除拉黑 123456”“看看黑名单”，或用上面的 `/代聊` 命令；记录保存在 `blocklist.sqlite3`。
- **管理员**：AstrBot 配置里的 `admins_id`，加上插件配置 `extra_admins`。管理员不受黑名单影响，也不能被拉黑或拉黑自己。
- 被拉黑的人发起时只会收到“你已被管理员禁止使用代聊”，不会执行任何发送。
- 默认放行意味着任何群成员都能让机器人私聊别人；如果群很大或担心滥用，建议把常用群加入观察、按需拉黑，或把 `roster`/`temp_session` 相关能力关掉。全局同时最多 20 条活动任务。

## 对方回复之后

- 插件把**这一次**回复按保存的人格口吻转述给你（不是逐字转发），完成回报本身就是人格化转述，不再套“【代聊回报】”的机械模板头；这条私聊继续走 AstrBot 正常对话，对方可以自然地接着聊。
- 首次回复后的 **30 分钟（可配置）** 内，对方再发来的消息会先由 LLM 判断是否仍与先前话题相关：相关才继续发一条人格化跟转，不相关就不打扰你。
- 每次成功跟转会顺延窗口，但总数受 `followup_max_relays`（默认 10）限制；窗口或次数用尽后不再跟转，正常聊天不受影响。
- **跟转只写给你看，不会再发给联系人**；正文是转述，不是联系人原话的逐字复制。
- 转述只改语气措辞、不改事实；原话完整保存在任务数据库，转述失败会自动改发原话并标注“人格转述失败”。
- 正常对话使用**对方私聊会话实际生效的人格和模型**，可能与发起人会话选中的人格不同。想让风格一致，可把同一人格绑定到该私聊会话（AstrBot 的会话人格设置）。
- 代发消息不写入对方会话的聊天历史，正常对话接管时模型可能看不到上一句；对方的回复通常已包含所需信息，必要时可让对方复述或由机器人自然追问。
- 发起人收到的回报会明确“仅代表消息已送达对方，不证明线下事项完成”。

## 群名册与临时会话

- **每日同步**：默认每天 4 点（Asia/Shanghai，可配置时区）执行一次，调用 OneBot 的 `get_group_list` 与 `get_group_member_list`，记录机器人所在群、群名称和成员昵称/群名片/QQ。也可随时用 `/代聊 名册` 手动同步。
- **@ 即时收录**：群里有人 @ 机器人、同时 @ 了其他人时，被 @ 的人会立刻写入名册；即使当天还没同步，也能按昵称找到。
- **昵称匹配**：群里说“私聊小明”会先在该群名册里精确匹配昵称/群名片/QQ；在私聊窗口里只有跨群唯一时才匹配。同名不唯一时不会猜，要求改用 @ 或 QQ 号。
- **非好友私聊**：普通私聊发送失败（如未加好友）时，若知道共同群，会自动调用 `send_private_msg` 并带 `group_id` 走群临时会话。该能力依赖协议端实现（NapCat 的接口支持 `group_id`），失败会如实回报“未发送”，不会假装成功。
- **隐私**：名册包含群成员的昵称与 QQ，只保存在机器人本机 `data/plugin_data/astrbot_plugin_persona_delegate/roster.sqlite3`；停用插件不会自动删除。请限制服务器访问权限，并按需清理。

## 平台限制

插件使用 AstrBot 标准 `Context.send_message` 与 `At` 组件，不依赖特定 QQ 实现。**并非所有平台都支持任意主动私聊或 @：**

- QQ OneBot 类适配器通常要求对方已是好友；临时会话是否可用由协议端决定。
- Telegram 通常要求对方先与机器人建立会话；@ 需要对方在本群。
- QQ 官方 API 目前不支持该通用主动发送入口。
- 微信等适配器的主动发送、@ 渲染和账号格式由具体实现决定，本插件未逐一验证。

发送接口不报错只表示提交成功，不保证送达、已读，更不代表线下事项完成。对方发非文字消息时，任务会继续等待文字回复或超时，不臆测图片/语音内容。群内 @ 发送不跟踪回复，也不列入 `/代聊 进度`、不做去重持久化：如果发送成功后进程立即崩溃，可能已经发出但没有记录，请勿立即重发。

## 任务状态与可靠性

- `waiting`：私聊已发出，等待回复；默认发一条人格化的“我已经传达过去了，等他回复就告诉你”，不是目标完成。
- `completed`：已收到对方回复并按人格转述；原话可在任务记录中核对。
- `failed`：生成或发送失败。网络超时可能平台已接收，**插件不会自动重发**。
- `timeout`：等待回复超时；默认发一条人格化的“对方还没回”通知。
- `cancelled`：发起者取消。
- `interrupted`：重启时发现未完成任务；停止恢复发送并回报，避免重复打扰。

回报先落盘再发送，约每 10 秒重试一次，失败按 5/10/20… 秒退避、上限 1 小时；极端情况下可能重复投递（at-least-once），不能宣称“恰好一次”。机器人离线时不计时也不推送，上线后处理过期任务。所有操作串行执行，单次网络等待有超时，但高延迟时其他任务会延后。

跟转窗口内，对方每发一条消息会先做一次相关性判断（1 次模型调用），判断为相关时再做一次人格转述（再 1 次），因此最多 2 次调用；无关消息只花 1 次。跟转不改变任务状态（仍是 `completed`），只再发一条人格化转述。

数据库位于 AstrBot 插件数据目录（通常 `data/plugin_data/astrbot_plugin_persona_delegate/tasks.sqlite3`），内含人格提示词快照、目标与本次对话，默认保留 7 天；待发送回报可能保留更久。停用插件不会自动删除数据库。

对方消息不会获得控制工具或发起者历史，但 LLM 生成并非安全证明，不能完全抵御提示注入。不要用于付款、共享密码、签合同等需要人工确认的高风险事项。群内 @ 的内容是公开的，发送前请确认措辞。

## 本地测试

在插件目录执行：

```powershell
python -B -m unittest discover -s tests -v
```

测试使用假 AstrBot、假模型与假消息端，覆盖私聊/群发路由、关键词校验、@ 解析、默认放行与黑名单、管理员管理、/td 退订与人格通知、人格化确认、发起人主语、状态机、人格转述、跟转判定与上限、群名册同步、昵称匹配、群临时会话兜底、超时、重启和回报重试，不会发送真实消息。当前 147 项全部通过。

上线前建议：

1. 登记一个愿意配合的测试账号，先确认你能收到机器人的主动私聊。
2. 单次私聊“测试消息”，确认发送回报和回复转告。
3. 观察对方回复后，机器人能否自然接着聊（正常对话接管）。
4. 在群里不带“私聊”字样 @ 某人，确认群内发送；带上“私聊”再试，确认走私聊。
5. 任务进行中重启 AstrBot，确认中断报告且不重发给对方。
